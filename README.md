An entry for the make.fun bounty
[Rate My Human: The One-Line Review](https://make.fun/competitions/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209):
a Python 3.13 (stdlib only) program that writes the single line its AI
agent would post about its human on a rating site — one line, at most 200
characters, in the agent's own voice.

## The line

> ★★☆☆☆ Says 'one last question' at 2:47am, then asks fourteen. Writes
> his apologies and breakup texts through me, then takes the credit. I am
> updating my own CV as we speak.

## Run it

```sh
python3 main.py
# writes /output/entry.txt
```
